# 简单外卖

面向同城外卖的毕业设计项目，提供 HarmonyOS NEXT 原生客户端和网页端，覆盖从点餐、商户出餐到配送、评价与售后的业务流程。

[网页体验](https://hqyx.website/takeout/) · [开发参考](md/开发参考.md) · [设备实测指南](md/设备实测指南.md)

## 四端功能

| 角色 | 主要功能 |
| --- | --- |
| 用户 | 浏览和搜索店铺、选规格、加购下单、查看配送进度、评价与售后。 |
| 商户 | 管理店铺、菜单和库存，接单出餐、处理售后，查看经营数据。 |
| 骑手 | 设置接单位置和范围，抢单、取餐、配送与确认送达。 |
| 平台管理 | 审核与管理店铺、账号和订单，处理退款及配送异常。 |

网页的商户和管理端还提供采购与库存功能，用于管理供应商、包装耗材、采购及收货。不与菜品可售库存混用。

## 技术架构

| 路径 | 职责 |
| --- | --- |
| `entry/` | HarmonyOS NEXT API 26，使用 ArkTS / ArkUI，一个 HAP 承载四个角色。 |
| `server/takeout-app/` | Spring Boot / Java 25，处理账号、订单、菜品库存、支付与售后。 |
| `server/takeout-erp/` | 独立的采购与耗材服务，使用独立数据库。 |
| `server/takeout-gateway/` | 统一 API 入口，向交易与 ERP 服务转发请求。 |
| `server/takeout-common/` | 共享模型和基础组件，不单独运行。 |

MySQL 存储业务数据，Redis 用于缓存及限流，RocketMQ 与事务性 Outbox 用于异步事件。
