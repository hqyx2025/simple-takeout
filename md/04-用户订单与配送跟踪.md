# 04 - 用户订单与配送跟踪模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/OrderDetailPage.ets`、`entry/src/main/ets/pages/Index.ets`（订单 Tab）、`entry/src/main/ets/components/OrderStatusTimeline.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

订单列表按状态 Tab 筛选；订单详情展示状态时间轴、配送信息、金额明细，支持取消订单、确认收货、再来一单、去评价；配送中订单展示骑手移动动画与预估送达时间。

## 二、业务逻辑判断

### 1. 订单加载（详情页 `aboutToAppear`）

```
orderId 来源：页面参数 orderId || AppStorage.get('currentOrderId') || 0
判断：在 orderList 中 find 该订单
  ├─ 找到 → 展示订单内容
  └─ 未找到 → 显示"订单不存在"空态
判断：order.status === 3（配送中）→ 启动骑手动画
```

### 2. 订单状态时间轴（`getDeliverySteps()`）

```
数据源：getDeliverySteps(status, createTime, payTime, deliverTime, completeTime)
规则：按当前订单状态生成 5 个节点（下单→接单→制作→配送→完成）
  - 已完成节点：时间取自对应时间字段
  - 未到达节点：time=''、completed=false
```

### 3. 取消订单（`cancelOrder(orderId)`）

```
触发：订单详情页弹窗确认"确定取消"
处理：orders.find(order) → 找到后：
  order.status = 5（已取消）
  order.cancelTime = 当前时间
结果：saveAllData() → reloadOrder() 刷新页面
```

> ⚠️ 代码层面**未限制可取消的状态**（待接单/制作中均可取消），页面按钮根据状态显示。

### 4. 确认收货（`confirmOrder(orderId)`）

```
触发：弹窗确认"确认已收到商品"
处理：order.status = 4（已完成）、order.completeTime = 当前时间
结果：saveAllData() → reloadOrder()
```

### 5. 再来一单（页面操作）

```
逻辑：将订单 items 逐条 addToCart（数量不变）
结果：加入购物车，可跳转结算
```

### 6. 骑手配送动画（`startRiderAnimation()`）

```
触发条件：订单状态 === 3（配送中）
逻辑：riderTimer = setInterval(250ms)：
  riderProgress += 0.02
判断：riderProgress >= 0.88 → 停止动画（预留终点缓冲）
清理：aboutToDisappear 时 stopRiderAnimation()（clearInterval）
```

### 7. 预估送达时间（`getEstimatedTime()`）

```
逻辑：下单时间起算，预估总时长 30 分钟
  elapsed = (当前时间 − createTime) / 分钟
  remain = 30 − elapsed
判断：remain < 5 → 强制为 5 分钟（保底显示）
结果：`预计 X 分钟送达`
```

## 三、操作按钮显隐规则（按状态）

| 订单状态 | 显示按钮 | 动作 |
|---|---|---|
| 1 待接单 | 取消订单 | 弹窗确认 → status=5 |
| 2 制作中 | 取消订单 | 弹窗确认 → status=5 |
| 3 配送中 | 确认收货 + 骑手动画 | 弹窗确认 → status=4 |
| 4 已完成 | 再来一单 + 去评价 | 加购 / 跳转 ReviewPage |
| 5 已取消 | 再来一单（如有） | 加购 |

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 订单不存在 | "订单不存在"空态，不崩溃 |
| createTime 格式兼容 | `replace(/-/g, '/')` 后再 new Date（兼容 iOS/部分模拟器） |
| 定时器泄漏 | aboutToDisappear 清理，动画达 0.88 自停 |
| 数据刷新 | 操作后 reloadOrder() 从 orderList 重新读取 |

## 五、数据流向

```
订单列表点击 → currentOrderId → OrderDetailPage
  → find 订单 → 渲染状态时间轴/配送/金额
  → 取消/确认收货 → cancelOrder/confirmOrder → saveAllData
  → 再来一单 → addToCart（回购物车）
```
