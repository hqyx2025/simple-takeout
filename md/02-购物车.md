# 02 - 购物车模块业务逻辑

> 涉及文件：`entry/src/main/ets/service/AppStorageManager.ets`、`entry/src/main/ets/pages/Index.ets`（发现 Tab 加购）、`entry/src/main/ets/pages/CheckoutPage.ets`

## 一、功能概述

支持跨店铺加购、同店同品数量合并、数量增减（减到 0 自动移除）、按店铺维度结算。
购物车数据持久化，App 重启不丢失。

## 二、业务逻辑判断

### 1. 加购逻辑（`addToCart(item)`）

```
输入：CartItem（含 goods、quantity、storeId、storeName）
判断：购物车中是否存在 同一商品(goods.id) 且 同一店铺(storeId) 的条目
  ├─ 存在 → 在原条目上 quantity += 新加数量（合并）
  └─ 不存在 → 作为新条目 push 进购物车
结果：更新 cartItems → saveAllData() → 记录日志
```

| 判断项 | 规则 | 说明 |
|---|---|---|
| 同品合并 | `goods.id === item.goods.id && storeId === item.storeId` | 同一店铺同一商品合并数量 |
| 跨店区分 | storeId 不同则视为不同条目 | 同一商品在不同店铺各自独立计数 |

> ⚠️ 合并条件同时校验 `goods.id` 与 `storeId`，防止不同店铺的同名商品被错误合并。

### 2. 数量修改逻辑（`updateCartItemQuantity(goodsId, storeId, quantity)`）

```
输入：商品ID、店铺ID、目标数量
判断1：quantity <= 0
  ├─ 是 → 从购物车中移除该条目（filter 删除）
  └─ 否 → 判断2
判断2：购物车中是否存在该条目
  ├─ 存在 → 更新 quantity
  └─ 不存在 → 忽略（不新增）
结果：更新 cartItems → saveAllData()
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 数量 ≤ 0 | `quantity <= 0` | 移除条目（等价删除） |
| 数量 > 0 | 找到条目后赋值 | 更新数量 |
| 条目不存在 | find 无结果 | 不执行任何操作 |

### 3. 清空购物车（`clearCart()`）

```
逻辑：cartItems 置为 [] → saveAllData()
触发场景：登出时调用（logout 内部）
```

### 4. 结算页购物车过滤

```
CheckoutPage.aboutToAppear：
  checkoutStoreId = AppStorage.get('checkoutStoreId')
  storeItems = cartItems.filter(c => c.storeId === checkoutStoreId)
判断：过滤后为空 → 显示"暂无结算商品"空态，隐藏结算栏
```

## 三、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| cartItems 为 undefined | `|| []` 兜底 |
| 加购未登录 | 页面层先校验 `isLoggedIn()`，未登录跳转登录页 |
| 同店多商品 | 每次加购只合并目标商品，其他条目不变 |
| 结算后残留 | 按店铺清空：对 storeItems 逐条调用 `updateCartItemQuantity(..., 0)` |

## 四、数据流向

```
店铺详情页"+"按钮 → addToCart()
  → AppStorage.cartItems（@StorageLink 自动刷新角标）
  → saveAllData() → preferences 持久化
结算页 → 过滤当前店铺条目 → 提交订单 → 逐条清零
```

| 事件 | 日志 | 级别 |
|---|---|---|
| 加购 | `加入购物车 goods=xxx x2 storeId=x` | Info |
