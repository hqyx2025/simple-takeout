# 03 - 下单结算模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/CheckoutPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

结算页展示收货地址、商品明细、金额计算、优惠券选择、备注输入，提交后模拟支付（LoadingIndicator 遮罩）生成订单，跳转订单详情页。

## 二、业务逻辑判断

### 1. 金额计算（三档金额 + 实付）

```
商品总价   = Σ(商品单价 × 数量)                    （getGoodsTotalPrice）
配送费     = 当前店铺 storeInfo.deliveryFee        （getDeliveryFee）
优惠金额   = 已选优惠券 coupon.amount，未选为 0    （getDiscountAmount）
实付金额   = 商品总价 + 配送费 − 优惠金额
判断：实付 < 0 → 强制取 0（getPayAmount 中 pay > 0 ? pay : 0）
```

| 计算项 | 规则 | 说明 |
|---|---|---|
| 商品总价 | 遍历 storeItems 累加 | 只统计当前结算店铺 |
| 配送费 | 取店铺 deliveryFee | 店铺信息不存在时为 0 |
| 优惠 | 已选券金额 | 未选券为 0，明细卡仅在 >0 时展示 |
| 实付保底 | `pay > 0 ? pay : 0` | 防止优惠超过总额出现负数 |

### 2. 优惠券可用性筛选（`getAvailableCoupons()`）

```
规则：couponList.filter(券 => !c.used && c.minOrder <= 商品总价)
判断1：已使用（c.used）→ 不可选
判断2：门槛（minOrder）> 商品总价 → 不可选
结果：满足两个条件的券进入选择列表；无可用券时弹窗显示"暂无可用优惠券"
```

### 3. 提交订单（`submitOrder()` → `doSubmitOrder()`）

```
触发：点击"提交订单"
判断1：submitting === true → 直接 return（防连点）
判断2：currentAddress === null → toast"请先添加收货地址" 并 return
通过 → submitting = true → 显示"支付处理中..."遮罩 → setTimeout 800ms 模拟支付
```

```
doSubmitOrder（800ms 后执行）：
  1. 组装 Order 对象：
     id = generateOrderId()（Date.now()+随机数）
     status = 1（待接单）
     createTime = 当前时间（YYYY-MM-DD HH:mm:ss）
     items = storeItems（引用当前店铺条目）
     address / remark / 各项金额
  2. addOrder(order) → 订单插入 orderList 头部，同步 user.orders
  3. 清空该店铺购物车：逐条 updateCartItemQuantity(..., 0)
  4. 若使用了优惠券 → useCoupon(券id)（标记 used=true）
  5. 写入 currentOrderId / currentOrder（供订单详情页读取）
  6. 重置 selectedCoupon = null
  7. submitting = false → toast"订单提交成功！" → pushUrl 订单详情页
```

## 三、关键业务规则总结

| 规则 | 判断 | 处理 |
|---|---|---|
| 地址必填 | currentAddress === null | 拦截提交，toast 提示 |
| 防重复提交 | submitting 标志位 | 连点无效 |
| 模拟支付 | setTimeout 800ms | 期间 LoadingIndicator 遮罩 |
| 优惠券核销 | 订单生成后 | 标记 used=true |
| 购物车清理 | 订单生成后 | 仅清空当前店铺条目 |
| 跳转参数 | currentOrderId | 订单详情页据此查找订单 |

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 结算页无商品（直接进入） | 显示空态"暂无结算商品"，无结算栏 |
| checkoutStoreId 未设置 | `|| 0`，过滤结果为空 → 空态 |
| 优惠券弹窗 | 半屏底部弹窗，点击遮罩/✕ 关闭；"不使用"选项可选（券传 null） |
| 备注超长 | TextArea maxLength=50 |
| 金额浮点 | toFixed(2) 展示，计算用原始 number |

## 五、数据流向

```
店铺详情"去结算" → AppStorage.checkoutStoreId → pushUrl CheckoutPage
  → 结算页计算金额/选券/填备注
  → 提交 → addOrder + 清购物车 + useCoupon
  → currentOrderId → 跳转 OrderDetailPage
```
