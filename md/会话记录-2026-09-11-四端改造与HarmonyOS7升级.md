| 文件 | 改动 |
| --- | --- |
| `build-profile.json5` | `targetSdkVersion`/`compatibleSdkVersion` → `26.0.0`（新版去掉 `(24)` 后缀，用语义化版本号） |

## 二、补齐的「未完成功能」

### 1. 评价闭环（按菜品 + 图文 + 商家回复 + 评分更新）
- `reviews` 表新增 `order_id / images / anonymous / reply / reply_time`；`SchemaMigration` 幂等补列。
- 评价改为**按菜品**：`reviews` 按 `(order_id, goods_id)` 防重，订单内全部菜品评价完才置 `orders.reviewed=1`。
- 评价后重算 `stores.rating` / `goods.rating`（均值）。
- 新增商家回复接口 `PUT /api/merchant/reviews/{id}/reply`、商户评价管理页 `MerchantReviewsPage`、用户评价匿名开关、店铺详情展示商家回复。

### 2. 优惠券核销防重 + 过期失效
- `markUsed` 改条件更新（`WHERE status=0`），失败回滚整单防并发重复用券。
- `expireOutdated` + `listCoupons` 惰性过期，过期未用券置 `status=2`。

### 3. 预约送达时间
- `orders` 新增 `expect_time`；`createOrder` 支持 `expectTime`（空=立即，非空须合法且晚于当前）。
- 结算页新增「送达时间」选择（立即 / 1小时后 / 2小时后）。

### 4. 首页 Banner / 公告（内容管理）
- 新增 `banners` / `announcements` 表 + `ContentService`。
- 公开接口 `GET /api/banners`、`GET /api/announcements`；管理端 `AdminContentController` CRUD + 启停。
- 首页轮播改为读服务端数据（空时回退默认），Banner 下方展示平台公告；管理端新增 `AdminContentPage`。

## 三、新增骑手端（四端）

### 数据模型
- `users.role=3`（RIDER）；新增 `riders` 表（在线状态/累计单量/收入）。
- `orders` 新增 `rider_id` / `ready_time`。

### 配送流程（抢单模式，不改数字状态码）
```
用户下单(1) → 商户接单(2) → 商户出餐(ready_time) → [待取餐池]
  → 骑手抢单(条件更新 rider_id) → 骑手取餐(2→3) → 骑手送达(3→4) → 用户确认收货(escrow 0→1)
```
- 抢单/取餐/送达均**条件更新**，防并发重复抢单；订单分配骑手后商户不得再标记配送/送达（`requireNoRider`）。

### 接口与页面
- 骑手端接口：`/api/rider/profile`、`/status`、`/orders/pool`、`/orders`、`/orders/{id}/grab|pickup|deliver`。
- 管理端：`AdminRiderController`（列表/启停）+ `AdminRiderPage`。
- 前端骑手端 3 页面：`RiderCenterPage`（上线开关/统计）、`RiderOrderPoolPage`（抢单大厅）、`RiderOrdersPage`（取餐/送达）；登录页新增「骑手配送」；`Index` 骑手角色守卫直达骑手中心。
- 用户端订单详情显示配送骑手姓名/电话（`OrderView` 加 `riderName/riderPhone`）。
