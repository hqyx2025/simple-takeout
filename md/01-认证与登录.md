# 01 - 认证与登录模块业务逻辑

> 涉及文件：`entry/src/main/ets/service/AppStorageManager.ets`、`entry/src/main/ets/pages/LoginPage.ets`、`entry/src/main/ets/model/Models.ets`

## 一、功能概述

支持用户注册、登录、登出，双角色体系（普通用户 CUSTOMER / 商户 MERCHANT）。
登录态与用户信息持久化，App 重启后保持登录。

## 二、业务逻辑判断

### 1. 登录逻辑（`login(phone, password)`）

```
输入：手机号、密码
判断：在 allUsers 中查找 phone 与 password 同时匹配的用户
  ├─ 找到 → 写入 AppStorage：user、isLoggedIn=true → saveAllData() → 返回用户对象
  └─ 未找到 → logWarn 记录失败日志 → 返回 undefined（页面提示"账号或密码错误"）
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 账号不存在 | `users.find()` 返回 undefined | 登录失败，提示错误 |
| 密码错误 | phone 匹配但 password 不匹配 | 登录失败，提示错误 |
| 登录成功 | phone + password 同时匹配 | 更新 user、isLoggedIn，持久化 |
| 角色识别 | 成功后根据 `user.role` 区分用户/商户 | 商户显示商户中心入口 |

### 2. 注册逻辑（`register(username, phone, password, role)`）

```
输入：昵称、手机号、密码、角色
判断1：手机号是否已存在（唯一性校验）
  ├─ 已存在 → 返回 undefined（提示"手机号已注册"）
  └─ 不存在 → 创建 User 对象（id=Date.now()，balance=0，空数组初始化）
判断2：创建成功后写入 allUsers → saveAllData() → 返回新用户
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 手机号唯一性 | `users.find(u => u.phone === phone)` | 重复则拒绝注册 |
| ID 生成 | `Date.now()` | 保证唯一 |
| 角色存储 | 注册时指定 role | 决定登录后入口（用户/商户） |

### 3. 登出逻辑（`logout()`）

```
触发：用户点击退出登录
处理：
  1. isLoggedIn = false
  2. user 重置为默认用户
  3. cartItems 清空
  4. clearAllData() 清除全部持久化数据（含登录态、订单、收藏、地址、优惠券）
```

> ⚠️ 注意：登出会**清空本地所有持久化数据**（包括购物车与订单），属于业务决策，需在设置页确认后执行。

### 4. 登录态判断（`isLoggedIn()`）

```
逻辑：return AppStorage.get<boolean>('isLoggedIn') || false
用途：
  - 加购/结算前校验是否登录（未登录引导跳转 LoginPage）
  - 商户入口仅对 role=MERCHANT 显示
```

## 三、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| allUsers 为空 | `|| []` 兜底，返回登录失败 |
| 未初始化 | `initAppStorage()` 启动时写入默认用户（含测试账号） |
| 持久化失败 | `saveAllData()` 内部 try/catch，不影响内存状态 |
| 登出后持久化残留 | `clearAllData()` 逐个 key delete + flush |

## 四、数据流向

```
LoginPage 输入
  → login() / register()
  → AppStorage（user / isLoggedIn / allUsers）
  → saveAllData() → preferences 文件（takeout_app_data）
  → 重启时 loadAllData() 恢复登录态
```

## 五、关键日志埋点

| 事件 | 日志 | 级别 |
|---|---|---|
| 登录成功 | `用户登录成功 phone=xxx userId=x role=商户/用户` | Info |
| 登录失败 | `用户登录失败 phone=xxx（账号或密码错误）` | Warn |
| 注册成功 | `用户注册成功 phone=xxx username=xxx role=xxx` | Info |
| 退出登录 | `用户退出登录，已清除登录态与购物车` | Info |
