# 09 - 优惠券模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/CouponCenterPage.ets`、`entry/src/main/ets/pages/CheckoutPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

优惠券中心三 Tab：可领取 / 我的优惠券（未使用）/ 已使用。支持领取去重、结算页按门槛筛选可用券、下单核销（标记已用）。

## 二、业务逻辑判断

### 1. 领取优惠券（`doClaim(coupon)`）

```
触发：可领取 Tab 点击"领取"
判断：couponList 中是否已存在同 id 优惠券（去重）
  ├─ 已存在 → 记录日志并 return（不重复领取）
  └─ 不存在 → 执行领取：
      1. 券加入 couponList（我的优惠券）
      2. 从 claimableCoupons 中移除该券
结果：按钮状态由"领取"变"已领取"（isClaimed 判断，enabled=false）
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 重复领取 | `couponList.some(c => c.id === coupon.id)` | 拦截 + Info 日志 |
| 领取成功 | 加入 couponList + 移出 claimableCoupons | UI 联动刷新 |
| 按钮状态 | isClaimed() 为 true | 置灰"已领取"，不可点击 |

### 2. 我的优惠券分类（`getUnusedCoupons` / `getUsedCoupons`）

```
未使用：couponList.filter(c => !c.used)
已使用：couponList.filter(c => c.used)
```

### 3. 结算页可用券筛选（`getAvailableCoupons()`）

```
规则：couponList.filter(c => !c.used && c.minOrder <= 商品总价)
判断1：c.used === true → 排除（已核销）
判断2：c.minOrder > 商品总价 → 排除（未达门槛）
结果：满足全部条件才出现在结算弹窗；无券显示"暂无可用优惠券"
```

### 4. 使用优惠券（`useCoupon(couponId)`）

```
触发：结算提交订单时（selectedCoupon 非 null）
判断：couponList 中 find 到该券
  ├─ 找到 → coupon.used = true（核销标记）
  └─ 未找到 → Warn 日志，不执行
结果：saveAllData() → 结算页同时重置 selectedCoupon = null
```

### 5. 结算页选择流程

```
点击优惠券卡片 → 弹窗（半屏）
  → CouponOption(null) 表示"不使用"
  → CouponOption(coupon) 每张可用券
选择后：selectedCoupon 写入 AppStorage（'selectedCoupon'）
  → 提交订单成功后重置为 null（防止下次结算残留）
```

## 三、状态流转

```
可领取(claimableCoupons) --领取--> 我的优惠券(couponList, used=false)
我的优惠券 --结算使用--> 已使用(couponList, used=true)
```

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 无可领取券 | 空态"暂无可领取的优惠券" |
| 无可用券 | 空态"暂无可用优惠券" |
| 券 id 冲突 | 领取去重判断，防止重复入账 |
| 结算未用券 | selectedCoupon 为 null → 优惠金额 0，不调用 useCoupon |
| 使用不存在的券 | find 无结果 → Warn 日志 |

## 五、数据流向

```
CouponCenterPage.doClaim → couponList + claimableCoupons（AppStorage）
结算页 getAvailableCoupons → 选择 → selectedCoupon
提交订单 → useCoupon(券id) → used=true
全程 saveAllData() 持久化 couponList
```

## 六、关键日志埋点

| 事件 | 日志 | 级别 |
|---|---|---|
| 重复领取 | `领取优惠券已领取过 couponId=x` | Info |
| 领取成功 | `领取优惠券成功 couponId=x 金额=x 门槛=x` | Info |
| 使用券 | `使用优惠券 couponId=x 金额=x` | Info |
| 使用失败 | `使用优惠券失败：优惠券不存在 couponId=x` | Warn |
