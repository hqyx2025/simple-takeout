## DevEco Studio 收尾步骤

1. 连接真机或启动模拟器，安装 Debug HAP，分别执行登录、选址确认、结算提交三个 UI 用例。
2. 执行 Code → Inspect Code，处理 ERROR；将 WARN（含 Entry 导出提示和异常处理提示）记录到审查报告。
3. 执行 Tools → AppAnalyzer 的规则体检、场景化体检、上架前体检并导出结果。
4. 使用真实发布证书填写签名配置，构建 Release APP，安装验证后再提交 AppGallery Connect。
5. 启动后端时使用 `--spring.profiles.active=https`，注入 `TAKEOUT_SSL_KEY_STORE*` 环境变量；客户端将 Release API 地址切换为真实 HTTPS 域名后进行联调。
