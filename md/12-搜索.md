# 12 - 搜索模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/SearchPage.ets`、`entry/src/main/ets/service/PreferencesHelper.ets`、`entry/src/main/ets/service/MockDataService.ets`

## 一、功能概述

首页进入搜索页：热门搜索 + 历史搜索（preferences 持久化）+ 店铺名称模糊搜索；点击搜索结果联动"发现"Tab 展示店铺详情。

## 二、业务逻辑判断

### 1. 执行搜索（`doSearch()`）

```
输入：搜索框文本
判断1：keyword = searchText.trim() 是否为空
  ├─ 空 → return（不执行搜索）
  └─ 非空 → 判断2
判断2：hasSearched = true，从 allStores 过滤
  searchResults = allStores.filter(s => s.name.includes(keyword))
结果：
  - 命中 0 家 → 空态"没有找到相关店铺"
  - 命中 > 0 家 → 列表渲染
  - 无论命中与否 → addSearchHistory(keyword) + 刷新历史列表
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 空关键词 | `trim() === ''` | 直接返回，不触发搜索 |
| 匹配方式 | `s.name.includes(keyword)` | 名称包含即命中（模糊匹配） |
| 搜索范围 | getAllStoresList() | 全部店铺（含商户新建） |
| 历史记录 | 每次成功搜索都写入 | 无命中也记录 |

### 2. 热门词点击（`searchByKeyword(word)`）

```
逻辑：searchText = word → doSearch()
判断：复用 doSearch 流程（热门词必非空）
```

### 3. 搜索历史管理（PreferencesHelper）

```
getSearchHistory()：prefs 读取 SEARCH_HISTORY_KEY，逗号分隔转数组
addSearchHistory(keyword)：
  1. 空关键词拦截（trim === '' return）
  2. 去重：history.filter(item => item !== keyword)
  3. 置顶：unshift(keyword)
  4. 限长：length > 10 → slice(0, 10)
  5. put + flush
clearSearchHistory()：删除 key + flush
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 去重 | 相同关键词只保留最新一条 | 重复搜索不累积 |
| 置顶 | unshift 插入头部 | 最近搜索排最前 |
| 限长 | MAX_HISTORY_SIZE=10 | 超长截断 |
| 空词 | trim 为空 | 不写入 |

### 4. 搜索结果进店联动

```
逻辑：onStoreClick(store)：
  AppStorage.setOrCreate('currentStoreId', store.id)
  router.back()
联动：返回首页 → 发现 Tab onPageShow 读取 currentStoreId → 展示店铺详情
```

## 三、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 历史为空 | 显示"暂无搜索历史" |
| 无搜索结果 | 空态"没有找到相关店铺" |
| preferences 读取失败 | getSearchHistory catch → 返回 [] |
| 写入失败 | addSearchHistory catch → Warn 日志，不影响主流程 |

## 四、数据流向

```
搜索框/热门词 → doSearch
  → getAllStoresList 过滤 → searchResults
  → addSearchHistory → preferences（takeout_preferences）
点击结果 → currentStoreId → router.back → 发现 Tab 联动
```

## 五、关键日志埋点

| 事件 | 日志 | 级别 |
|---|---|---|
| 执行搜索 | `执行搜索 keyword=x 命中x家店铺` | Info |
| 添加历史 | `添加搜索历史 keyword=x 当前共x条` | Info |

| 历史写入失败 | `添加搜索历史失败 keyword=x` | Warn |
