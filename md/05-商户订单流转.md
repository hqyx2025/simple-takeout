# 05 - 商户订单流转模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/MerchantOrdersPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

商户查看自己名下所有店铺的订单（按状态 Tab 筛选），执行 接单 → 出餐 → 确认送达 三步状态流转；订单完成后商户余额自动增加订单实付金额。

## 二、业务逻辑判断

### 1. 订单归属过滤（`getMerchantOrders(merchantId)`）

```
步骤1：getStoresByOwner(merchantId) → 商户名下所有店铺（storeIds）
步骤2：orderList.filter(o => storeIds.includes(o.storeId))
判断：订单的 storeId 是否属于该商户的店铺集合
  ├─ 属于 → 进入商户订单列表
  └─ 不属于 → 过滤掉（用户订单/其他商户订单不可见）
```

### 2. 状态 Tab 筛选（`getFilteredOrders()`）

```
判断：currentStatus === -1（全部）
  ├─ 是 → 返回全部订单
  └─ 否 → 只返回 status === currentStatus 的订单
Tab：全部(-1) / 待接单(1) / 制作中(2) / 配送中(3) / 已完成(4)
```

### 3. 接单（`merchantAcceptOrder(orderId)`）— 1 → 2

```
前置判断：order 存在 且 order.status === 1（待接单）
  ├─ 满足 → status = 2（制作中）、payTime = 当前时间
  └─ 不满足 → logWarn"订单不存在或状态不符"，不执行
结果：saveAllData() → 页面 loadOrders() 刷新 → toast"已接单"
```

### 4. 出餐（`merchantStartDelivery(orderId)`）— 2 → 3

```
前置判断：order 存在 且 order.status === 2（制作中）
  ├─ 满足 → status = 3（配送中）、deliverTime = 当前时间
  └─ 不满足 → 拦截
结果：saveAllData() → 刷新 → toast"已出餐，配送中"
```

### 5. 确认送达（`merchantCompleteOrder(orderId)`）— 3 → 4

```
前置判断：order 存在 且 order.status === 3（配送中）
  ├─ 满足 → status = 4（已完成）、completeTime = 当前时间
  │   附加：当前用户为 MERCHANT 角色 → user.balance += order.payAmount（收入入账）
  └─ 不满足 → 拦截
结果：saveAllData() → 刷新 → toast"已确认送达"
```

## 三、状态流转合法性矩阵

| 当前状态 | 接单 | 出餐 | 确认送达 | 说明 |
|---|---|---|---|---|
| 1 待接单 | ✅ →2 | ❌ | ❌ | 仅可接单 |
| 2 制作中 | ❌ | ✅ →3 | ❌ | 仅可出餐 |
| 3 配送中 | ❌ | ❌ | ✅ →4 | 仅可确认送达 |
| 4 已完成 | ❌ | ❌ | ❌ | 终态 |
| 5 已取消 | ❌ | ❌ | ❌ | 终态（不在商户列表） |

> 核心防呆机制：每个流转函数均带 `order.status === X` 前置校验，非法流转一律拦截并记录 Warn 日志。

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 商户无店铺 | getStoresByOwner 返回空 → storeIds 为空 → 订单列表为空态 |
| 订单不存在 | find 无结果 → 不执行 + Warn 日志 |
| 状态不符 | 前置校验失败 → 不执行 + Warn 日志 |
| 余额入账 | 仅 MERCHANT 角色且 status===3 → 完成时加 payAmount |
| 已取消订单 | 状态 5 不出现在商户 Tab 中（Tab 无"已取消"） |

## 五、数据流向

```
商户订单页（MerchantOrdersPage）
  → getMerchantOrders(merchantId) 过滤归属
  → handleAccept/handleStartDelivery/handleComplete
  → AppStorageManager 状态流转（带前置校验）
  → saveAllData() 持久化
  → loadOrders() 刷新列表
```

## 六、关键日志埋点

| 事件 | 日志 | 级别 |
|---|---|---|
| 接单 | `商户接单 orderId=x（待接单 -> 制作中）` | Info |
| 出餐 | `商户出餐配送 orderId=x（制作中 -> 配送中）` | Info |
| 送达 | `商户确认送达 orderId=x（配送中 -> 已完成）收入=x` | Info |
| 非法流转 | `商户接单失败：订单不存在或状态不符 orderId=x` | Warn |
