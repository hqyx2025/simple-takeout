# 10 - 收藏模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/FavoriteListPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

用户收藏/取消收藏店铺，收藏列表展示，点击收藏店铺联动跳转店铺详情。收藏数据持久化，按用户隔离（多账号各自收藏独立）。

## 二、业务逻辑判断

### 1. 切换收藏（`toggleFavorite(storeId)`）→ 返回 boolean

```
前置判断：当前用户是否存在（user === undefined/null）
  ├─ 不存在 → 返回 false（不执行）
  └─ 存在 → 判断2
判断2：收藏列表中是否存在 该用户 + 该店铺 的收藏记录
  ├─ 存在 → 取消收藏：filter 移除该记录 → 返回 false
  └─ 不存在 → 添加收藏：
      店铺必须存在（allStores.find）
      ├─ 找到店铺 → 创建 Favorite（id=Date.now()，快照店名/店图/时间）→ push → 返回 true
      └─ 店铺不存在 → 不添加，返回 false
结果：saveAllData()
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 未登录 | user 为空 | 返回 false，不执行任何操作 |
| 已收藏 | userId + storeId 双匹配 | 移除（取消收藏） |
| 未收藏 | 双条件不匹配 | 添加收藏记录 |
| 店铺不存在 | allStores 找不到 | 不添加 |

> 收藏记录以 `userId + storeId` 为唯一性键，同一用户对同一店铺只会有一条记录。

### 2. 查询我的收藏（`getFavorites()`）

```
前置判断：user 存在
  ├─ 不存在 → 返回 []
  └─ 存在 → favoriteList.filter(f => f.userId === user.id)
```

### 3. 收藏状态判断（`isFavorited(storeId)`）

```
前置判断：user 存在（否则 false）
判断：favoriteList.some(f => f.storeId === storeId && f.userId === user.id)
用途：店铺详情页收藏按钮的实心/空心状态
```

### 4. 收藏列表点击进店

```
逻辑：AppStorage.setOrCreate('currentStoreId', store.id) → router.back()
联动：首页"发现"Tab onPageShow 读取 currentStoreId → 展示对应店铺详情
```

## 三、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| favoriteList 未初始化 | `|| getDefaultFavorites()` 兜底 |
| 未登录访问收藏页 | 收藏列表为空（getFavorites 返回 []） |
| 多账号数据隔离 | 所有查询均带 userId 过滤 |
| 收藏店铺被删除 | 收藏记录保留（快照店名/图），点击后店铺不存在显示兜底 |

## 四、数据流向

```
店铺详情❤️ → toggleFavorite → favoriteList（AppStorage）
  → saveAllData() 持久化
  → FavoriteListPage.getFavorites 过滤当前用户 → 列表渲染
  → 点击 → currentStoreId → 发现 Tab 联动
```
