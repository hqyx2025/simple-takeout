> HarmonyOS NEXT 外卖应用（毕业设计） | 技术栈：ArkTS / ArkUI / AppStorage / preferences

## 一、整体业务闭环

```
用户端：搜索 → 浏览店铺 → 加购 → 结算 → 下单 → 订单跟踪 → 评价
商户端：接单 → 出餐 → 配送 → 完成（收入自动入账）→ 数据统计
数据层：AppStorage（内存共享）⇄ DataPersistence（持久化）⇄ 日志服务（全链路埋点）
```

## 三、订单状态机（全局核心状态）

```
状态码：1=待接单  2=制作中  3=配送中  4=已完成  5=已取消

用户端触发：提交订单(→1)  取消订单(1|2 →5)  确认收货(3 →4)
商户端触发：接单(1 →2)  出餐(2 →3)  确认送达(3 →4)

合法流转：1 → 2 → 3 → 4
非法流转：跳状态、逆向流转（4→3、5→2）均被拦截（代码有状态前置判断）
```

| couponList | Coupon[] | ✅ | 我的优惠券 |

| allStores / allGoodsMap | StoreItem[] / Map | ❌ | 店铺与商品 |

| _persistenceReady | boolean | ❌ | 持久化完成标记 |

## 五、通用边界处理原则

1. **空态兜底**：所有列表为空时展示 EmptyState，不崩溃
2. **数据防御**：读取 AppStorage 均带 `|| []` / `|| 默认值` 兜底
3. **状态校验**：商户状态流转前必须校验当前状态，不满足直接拦截
4. **防重复提交**：结算页 `submitting` 标志位防连点
5. **持久化归一化**：恢复数据先 normalize 再写入，防旧版本缺字段崩溃
