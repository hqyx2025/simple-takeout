# UI 与图标

四端的 43 个页面统一沿用登录页视觉：暖白页面、深棕文字、陶橙强调色、细描边与圆角控件。业务数据、路由、订单状态与角色权限沿用现有实现。

## 共用实现

- `common/theme/AppTheme.ets` 是共享基准；登录页直接使用它，首页通过 HomeTheme 复用同套颜色，旧页面通过 Constants 的语义资源使用相同配色。
- PageHeader 统一标题、44vp 返回/动作按钮，顶部留白计入总高度。购物车、助手、收入统计、隐私和评价图片预览页已接入。
- 表单统一 52vp 输入框、提示色、焦点描边；普通按钮使用圆角矩形。自定义内容按钮保留内容高度，避免账户卡片被压缩。
- 卡片使用细描边；常用表单与确认弹窗最大宽度 460vp；搜索栏、底部购物车、空状态与四端入口同步调整。商户新增/编辑店铺表单固定标题和操作栏，中间字段可滚动。
- 平台管理的退出登录位于底部并带确认，保留 `admin-center-logout` 定位 ID。
- 成功、失败、告警、订单制作状态仍使用独立语义色。浅色/深色主题的主要文字组合对比度均不少于 4.5:1。

## SVG 资源

新增 17 对 SVG（共 34 个文件）：线条图标、收藏选中态、默认餐品插图。页面中的系统符号和装饰 emoji 已替换为同套本地 SVG；已有登录、首页、个人中心图标直接复用。

`base/media` 与 `dark/media` 使用同名资源自动切换。默认商品图使用 `food_placeholder.svg`，用户与商户上传的照片继续通过 merchantImageSource 读取真实图片。

## 验证

2026-09-26：debug HAP 构建成功，LoginFlow、AdminFlow 设备用例通过。AdminFlow 验证管理员直接进入后台、10 个管理入口可见，以及分类、店铺、订单、退款、统计、内容页面往返。实测发现快捷登录弹窗入场动画期间测试可能多点一次，已让公共测试助手等待弹窗出现并重新获取控件。

构建、设备用例和截图记录保存在 `TemporaryCacheStorage/agent-ui-*`，均为本地临时产物。本文件不作为测试计划或阶段审批门禁。

静态检查覆盖 43 个页面、40 条注册路由、全部颜色/媒体引用及 SVG XML。深浅色资源的配对和关键文字对比度已验证。设备验证使用 API 26 模拟器和独立测试数据库，不代表实体设备或全部业务链路回归。

展开屏已检查登录、首页、个人中心、设置、平台管理、骑手中心及商户长表单。商户新增表单可滚动到配送半径，底部取消/创建按钮保持可见。真机、窄屏及深色模式的实屏效果尚未完成验证。
