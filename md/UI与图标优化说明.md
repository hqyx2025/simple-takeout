# UI 与图标优化说明

本次改动沿用已确认的暖白底色、橙色重点色和统一线条图标，保持 API 26、现有 V1 状态管理、后端接口及原有业务流程。

## 界面与交互

- 登录页：调整标题、角色选择、表单与登录/注册入口；保留可滚动表单、固定版本入口和快捷测试账号。窄屏收紧间距，输入框与提交按钮保持 52vp。
- 首页：统一地址、搜索、分类、常用入口及导航图标；图标与圆角背景分开绘制，避免线条裁切。修复展开再折叠后当前 Tab 丢失的问题。
- “我的”：重排账户信息、余额/优惠券/订单、订单状态和常用服务；保留真实数据、角色入口、充值及退出登录行为。
- 底部导航：统一 Tab 栏、页面底色与系统导航区域颜色，消除底部白色断层；选中项使用橙色图标和浅色底。
- 图标：51 种本地原创 SVG，按 `base` / `dark` 明暗配对，共 102 个文件，无外链资源依赖。
- 动效：由 `AppMotion` 统一 40 个页面的 Push/Pop 进入与退出过渡；Tab 切换 220ms，相关按钮按压 100ms。加载组件改用原生 `LoadingProgress`，确认弹窗统一淡入淡出；响应系统“减少动态效果”设置。
