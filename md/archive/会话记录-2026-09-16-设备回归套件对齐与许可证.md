## 二、设备回归套件三处漂移对齐（`8654ff6`）

### 1. Tab 收敛（我的页购物车行删 + 订单 Tab 删）

- `CheckoutGuard` / `CheckoutFlow`：购物车入口改用底部 `tab-2`（原 `profile-cart-entry` 已删）。
- `ReviewFlow`：订单入口改「我的 → 已完成」快捷入口；返回链补 `OrderListPage` 一层（订单列表已变为独立路由页，比旧「订单 Tab」多一层）。

### 2. §11 起送价服务端权威（客户端不再前置拦截）

- `CheckoutFlow` 负路径改判：低于起送价提交 → 请求照发、后端 400 → 弹「提交订单失败」→ 点「知道了」仍停结算页。
- `device-checkout-regression.ps1` host 计数从「下单请求 0」改「2 次 POST」，再因 hilog 系统日志洪泛致精确计数不可靠，最终放宽为 `>= 1`（失败弹窗断言 + exactly-one-new-order 承载真实契约）。

### 3. 骑手链条口径（商户只到 ready 出餐）

- `MerchantFlow` 按钮文案断言 `出餐` → `出餐完成`（骑手链重构后商户按钮改名）。
- `device-merchant-regression.ps1` host 口径 `status 4` → `status 2`（商户接单 1→2 + 出餐 ready，2→3→4 归骑手端）。

> 顺带补两个 `.ps1` 的 UTF-8 BOM（防 PS 5.1 中文 mojibake）。
