# 会话记录：全量页面 UI 布局检查与美化

日期：2026-09-09

## 用户需求

> 帮我检查各个页面的UI布局设计，我需要美化UI布局页面。

经确认，本次范围：**全部页面（用户端 + 商户端 + 管理端）**，方向：**一致性优先 + 组件复用**（低风险，保留现有干净卡片风格）。

## 设计体系

项目已有成熟的设计令牌（`common/Constants.ets` 的 `COLORS/SPACING/FONT_SIZE/BORDER_RADIUS`），本次在保留既有风格的基础上，补充并统一了散落的硬编码值。

### 新增令牌（Constants.ets）

- `COLORS.WARM_BG = '#FFF3E8'` 暖色浅底（快捷入口图标 / 浅色按钮底）
- `COLORS.OVERLAY = 'rgba(0,0,0,0.5)'` 遮罩（统一 0.5 / 0.35）
- `COLORS.ERROR_LIGHT = '#FFF0F0'` 错误浅底
- `COLORS.SUCCESS_LIGHT = '#E8F5E9'` 成功浅底
- `COLORS.WARNING_LIGHT = '#FFF7E6'` 警示浅底

### 新增组件（components/StatusBadge.ets）

通用状态药丸，`mode = primary | success | warning | error | gray`，统一了各端“状态只是纯色文字”的问题。

## 审计发现（问题清单）

对约 30 个页面并行审计后，跨页面共性问题：

1. **顶部导航不一致**：返回是 `‹` 还是 `‹ 返回`、标题 XL/LG、高度 44/48/56、安全区内边距不一。
2. **硬编码色绕过令牌**：`#F5F5F5`、`#FF3B30`、`#FF9800`、`#4CAF50`、`#F0F0F0`、`#666666`、暖色系 `#FFF1EB/#FFF8F0/#FFF3E0/#FFF3E8/#FFF7ED/#FFF1F0/#FFF8F3`、`rgba(...)` 遮罩。
3. **状态无药丸**：管理端/商户端状态仅纯色文字。
4. **原生数字间距**：`space:4/8/12`、标签 `padding 6/2`、高度 44/48/32。
5. **布局缺陷**：首页头部地址+搜索在 Column 中**上下堆叠**；订单详情操作按钮在 Scroll 内会随内容滚走；登录页无 Scroll 键盘遮挡注册输入框；购物车 `if(true)` 死代码；搜索页热门搜索（数据恒空）渲染空卡片；若干低对比禁用态。
6. **统计页橙色过载**：8 个指标全用 PRIMARY，仅主指标应高亮。

已良好、未改动的地方：`Scroll + layoutWeight(1)` + 底部固定栏基本正确、卡片 `BG_WHITE + BORDER_RADIUS.LG`、主力按钮为胶囊、数据均走 service 层。

## 已完成修改

### 1. 布局缺陷修复

- **首页头部**：地址 + 搜索由上下堆叠改为左右并排（`Row` + 搜索 `layoutWeight(1)`），并修复搜索框背景为 `BG_PRIMARY`。
- **订单详情**：操作按钮移出 Scroll，改为**固定底部操作栏**（含顶部细分隔线）。
- **登录页**：内容包裹进 `Scroll`，避免键盘遮挡注册输入框（曾误用无效的 `keyboardAvoidMode`，已移除）。
- **购物车**：移除死代码 `if(true)`，删除按钮配色改用 `ERROR_LIGHT`。
- **搜索页**：`hotWords` 恒为空时不再渲染“热门搜索”空白卡片。
- **设置 / 地址列表 / 搜索**：导航栏统一（高 56、标题 XL 居中）、低对比禁用态修复。

### 2. 一致性 + 令牌化（全量页面）

- 顶部导航统一：返回 `‹ 返回`、标题居中（XL）、右侧等宽占位、高度统一。
- 硬编码色统一映射令牌：`#F5F5F5→BG_PRIMARY`、`#F0F0F0→BG_PRIMARY`、`#FF3B30→PRICE_RED`、`#FF9800→WARNING`、`#4CAF50→SUCCESS`、`#666666→TEXT_SECONDARY`、`#FFF3E0→TAG_BG`、`#FFF0F0→ERROR_LIGHT`、`#E8F5E9→SUCCESS_LIGHT`、暖色→`WARM_BG`、`rgba(0,0,0,0.5/0.35)→OVERLAY`、`Color.White→TEXT_WHITE` / `BG_WHITE`。
- `space:4/8/12→SPACING.XS/SM/MD`。
- 标签 `padding/圆角` 等改用 `SPACING.*`、`BORDER_RADIUS.*`。

### 3. 管理端 & 商户端专项

- 状态改用药丸徽章：`营业中/已暂停`、`上架中/已下架`、`正常/已停用`、`启用中/已停用`（`StatusBadge`）。
- 筛选 / 分段按钮补胶囊样式；订单筛选 Tab 增加激活指示（2px PRIMARY 边框 + 浅底）。
- 统计页：仅“累计成交”保留 PRIMARY，其余 7 项改 `TEXT_PRIMARY`（缓解橙色过载）。
- 商户端：输入框高度统一 44、新增/编辑弹窗宽度 `88%` 统一、空状态尺寸统一、弹窗遮罩与背景统一。
- 各端可滚动内容补底部安全内边距 `SPACING.XXL`。

## 构建验证结果

- DevEco / hvigor：`BUILD SUCCESSFUL`。
- 编译期仅有的 2 个 `ArkTS Compiler Error`（`keyboardAvoidMode` 非 `Scroll` 属性）已在提交前修复。
- 其余仅为预存在的非阻塞 WARN（`@Entry` 导出提示、fastjson2 `Unsafe` 弃用、未配置签名）。
