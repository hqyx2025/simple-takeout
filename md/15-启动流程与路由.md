# 15 - 启动流程与路由模块业务逻辑

> 涉及文件：`entry/src/main/ets/entryability/EntryAbility.ets`、`entry/src/main/ets/pages/Index.ets`、`entry/src/main/resources/base/profile/main_pages.json`、`entry/src/main/module.json5`

## 一、功能概述

应用启动时序：Ability 生命周期 → 上下文注入 → 日志初始化 → 持久化恢复 → 首页 Tab 渲染。路由采用 `@ohos.router`（pushUrl/back），13 个路由页面注册于 main_pages.json；跨页联动通过 AppStorage 参数（currentStoreId / currentOrderId / checkoutStoreId）实现。

## 二、启动流程（EntryAbility）

```
onCreate：
  1. setColorMode（COLOR_MODE_NOT_SET，异常 catch）
  2. AppStorage.setOrCreate('appContext', this.context)   ← 必须最先（持久化/日志依赖）
  3. initLogger()                                          ← 初始化日志服务
  4. loadAllData()                                         ← 异步恢复持久化数据
onWindowStageCreate：
  windowStage.loadContent('pages/Index')
  → 加载首页，Index.aboutToAppear → initAppStorage() 兜底
```

| 步骤 | 依赖 | 失败处理 |
|---|---|---|
| setColorMode | 无 | catch + hilog.error，不影响启动 |
| appContext 注入 | 无 | — |
| initLogger | appContext | 降级为仅控制台日志 |
| loadAllData | appContext | catch → Error 日志，AppStorage 保持默认值 |
| loadContent | 无 | err.code 非 0 → hilog.error |

## 四、跨页联动参数

| 参数键 | 写入方 | 读取方 | 用途 |
|---|---|---|---|
| currentStoreId | 搜索页/收藏页 | Index 发现 Tab（onPageShow） | 点击店铺联动展示详情 |
| checkoutStoreId | 店铺详情"去结算" | CheckoutPage | 指定结算店铺 |
| currentOrderId | CheckoutPage | OrderDetailPage | 定位订单 |
| currentOrder | CheckoutPage | OrderDetailPage（兜底） | 订单快照 |
| selectedCoupon | 结算页选券 | 结算页（跨页停留） | 已选优惠券 |

## 五、联动流程判断

```
搜索/收藏点击店铺：
  setOrCreate('currentStoreId', id) → router.back()
  → Index 发现 Tab onPageShow：
    判断 currentStoreId 是否存在
    ├─ 是 → 加载该店铺详情
    └─ 否 → 默认展示推荐店铺

去结算：
  店铺详情"去结算" → setOrCreate('checkoutStoreId', storeId)
  → pushUrl CheckoutPage
  → aboutToAppear 过滤当前店铺购物车条目

订单详情：
  CheckoutPage.doSubmitOrder → setOrCreate('currentOrderId', order.id)
  → pushUrl OrderDetailPage → aboutToAppear find 订单
```

## 六、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 参数缺失（直接进入页面） | `|| 0` 兜底 → 空态展示 |
| 持久化未完成即渲染 | _persistenceReady 判断 + initAppStorage 双保险 |
| loadContent 失败 | hilog.error 记录 |
| 页面返回 | router.back()（搜索/收藏场景通过 onPageShow 联动刷新） |

## 七、关键日志埋点

| 事件 | 日志 | 级别 |
|---|---|---|
| Ability 创建 | `Ability onCreate` | Info |
| 日志初始化 | `Logger initialized, log file: xxx` | Info |
| 首页加载 | `initAppStorage 完成，全局数据初始化就绪` | Info |
| 各页进入 | `进入XX页 XxxPage` | Info |
