# 07 - 商户收入统计模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/MerchantStatsPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

展示商户今日/本周/累计数据卡片、近 7 天收入折线图、今日订单状态分布柱状图（Canvas 自绘）。所有统计以订单数据实时计算，无独立统计存储。

## 二、业务逻辑判断

### 1. 今日统计（`getMerchantTodayStats(merchantId)`）

```
数据源：getMerchantOrders(merchantId) → 商户名下所有订单
过滤：todayStr = 今天日期(YYYY-MM-DD)
  todayOrders = orders.filter(o => o.createTime.startsWith(todayStr))
  completedOrders = todayOrders 中 status === 4
统计口径：
  todayOrders   = 今日下单数（含未完成）
  todayRevenue  = 今日已完成订单 payAmount 之和
  completedOrders = 今日完成单数
  totalOrders   = 历史全部订单数
  totalRevenue  = 历史已完成订单 payAmount 之和
```

| 指标 | 判断口径 | 说明 |
|---|---|---|
| 今日单量 | createTime 以今日日期开头 | 含待接单等未完成单 |
| 今日收入 | status === 4 且 createTime 为今日 | 仅统计已完成订单 |
| 累计收入 | status === 4 的全部订单 | 不受时间限制 |

### 2. 近 7 天统计（`getMerchantWeekStats(merchantId)`）

```
过滤：weekAgo = 当前时间 − 7天
  weekOrders = 订单 createTime(转 Date 后) >= weekAgo
统计口径：与今日统计一致，但时间窗为近 7 天
```

> ⚠️ 注意：`createTime.replace(/-/g, '/')` 后再 `new Date()` 保证日期解析兼容性。

### 3. 近 7 天收入序列（`getMerchantWeekRevenue(merchantId)`）— 折线图

```
逻辑：从 6 循环到 0（逆推 7 天，含今日）
  dayStr = 第 i 天日期字符串
  每日收入 = 订单中 status===4 且 completeTime 以 dayStr 开头 的 payAmount 之和
返回：number[7]，索引 0 = 7 天前，索引 6 = 今日
```

> ⚠️ 与"近7天统计"口径不同：本函数按 **completeTime（完成时间）** 归集，而非 createTime。

### 4. 今日订单状态分布（`getMerchantTodayStatusOrders(merchantId)`）— 柱状图

```
过滤：今日订单（createTime 以今日开头）
遍历计数：
  status===1 → dist[0]（待接单）
  status===2 → dist[1]（制作中）
  status===3 → dist[2]（配送中）
  status===4 → dist[3]（已完成）
  status===5 → dist[4]（已取消）
返回：number[5]
```

## 三、统计口径对比表

| 维度 | 函数 | 时间字段 | 过滤条件 | 结果 |
|---|---|---|---|---|
| 今日卡片 | getMerchantTodayStats | createTime | 今日 | 单量/收入/总数 |
| 周卡片 | getMerchantWeekStats | createTime | 近7天 | 单量/收入/总数 |
| 折线图 | getMerchantWeekRevenue | completeTime | 近7天逐日 | 每日收入数组 |
| 柱状图 | getMerchantTodayStatusOrders | createTime | 今日 | 5 状态计数 |

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| 商户无订单 | 全部指标为 0，图表画空数据（正常渲染） |
| 状态字段缺失 | 归一化时 status 兜底为 1 |
| completeTime 缺失 | `?? ''` 兜底，不参与完成收入统计 |
| 跨天边界 | 日期字符串 startsWith 判断，无时区问题 |

## 五、数据流向

```
MerchantStatsPage.aboutToAppear
  → getMerchantTodayStats / getMerchantWeekStats / getMerchantWeekRevenue / getMerchantTodayStatusOrders
  → 全部由 getMerchantOrders 实时计算
  → Canvas 组件按 ctx.width/height 自适应绘制图表
```
