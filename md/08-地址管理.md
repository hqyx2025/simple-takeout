# 08 - 地址管理模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/AddressListPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

收货地址的增删改查、设置默认地址。地址列表持久化，结算页读取当前选中地址。

## 二、业务逻辑判断

### 1. 新增地址（`addAddress(address)`）

```
判断1：新地址 isDefault === true
  ├─ 是 → 先遍历旧列表将所有地址 isDefault 置 false（默认唯一性）
  └─ 否 → 直接添加
判断2：address.id = list.length + 1（自增分配）
结果：push 进列表 → saveAllData()
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 默认唯一 | 新增默认地址时清空其他默认标记 | 仅一个 isDefault=true |
| ID 分配 | `list.length + 1` | ⚠️ 删除后可能复用 ID（length 变化），为现有实现约束 |
| 首条地址 | 列表为空时 length=0 → id=1 | 正常 |

### 2. 删除地址（`deleteAddress(addressId)`）

```
处理：list = list.filter(a => a.id !== addressId) → saveAllData()
⚠️ 约束：当前实现未做兜底——
  - 删除默认地址后，不自动指定新的默认地址
  - 删除最后一条地址后，列表为空
```

### 3. 默认地址选择（`initAppStorage` 阶段）

```
逻辑：addressList 初始化时
  defaultAddr = addresses.find(a => a.isDefault) || addresses[0]
结果：currentAddress = defaultAddr（结算页默认选中项）
```

### 4. 结算页地址联动

```
规则：结算页读取 AppStorage.get('currentAddress')
地址列表页选择地址 → 更新 currentAddress → 返回结算页自动刷新
```

## 三、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| addressList 为空 | `|| []` 兜底，新增第一条 id=1 |
| 无默认地址 | 取列表第一条作为 currentAddress |
| 删除默认地址 | ⚠️ 无自动转移逻辑（当前实现限制，可作增强点） |
| 地址为空提交结算 | 结算页拦截：toast"请先添加收货地址" |

## 四、数据流向

```
AddressListPage 增删改 → addAddress/deleteAddress → addressList
  → saveAllData() 持久化
  → currentAddress 同步 → CheckoutPage 展示收货地址卡片
```
