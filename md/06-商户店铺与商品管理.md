# 06 - 商户店铺与商品管理模块业务逻辑

> 涉及文件：`entry/src/main/ets/pages/MerchantCenterPage.ets`、`entry/src/main/ets/service/AppStorageManager.ets`

## 一、功能概述

商户创建/编辑店铺信息、管理名下商品（新增、删除、编辑、上下架、改价）。店铺与商品数据保存在 AppStorage（allStores / allGoodsMap），不参与持久化（重启回默认）。

## 二、业务逻辑判断

### 1. 创建店铺（`createStore(store)`）

```
处理：
  1. store.id = Date.now()（唯一）
  2. stores.push(store)
  3. 初始化该店铺商品列表为空：goodsMap[store.id] = []
  4. 判断：当前用户为 MERCHANT 角色 → user.storeIds.push(store.id)
  5. saveAllData()
```

| 判断项 | 规则 | 结果 |
|---|---|---|
| 店铺 ID | Date.now() 生成 | 全局唯一 |
| 商品初始化 | goodsMap 自动建空数组 | 新店无商品 |
| 归属登记 | 仅 MERCHANT 角色 | storeIds 记录店铺归属 |

### 2. 更新店铺（`updateStore(store)`）

```
判断：stores.findIndex(s => s.id === store.id) >= 0
  ├─ 存在 → 整体替换 stores[index] = store
  └─ 不存在 → logWarn"店铺不存在"，不执行
结果：saveAllData()
```

### 3. 新增商品（`addGoodsToStore(storeId, goods)`）

```
处理：
  1. 取该店铺商品数组（无则空数组）
  2. goods.id = Date.now()
  3. push 后写回 goodsMap[storeId]
  4. saveAllData()
```

### 4. 删除商品（`removeGoodsFromStore(storeId, goodsId)`）

```
处理：storeGoods = storeGoods.filter(g => g.id !== goodsId) → 写回
判断：商品不存在时 filter 结果不变，删除操作天然幂等
```

### 5. 更新商品（`updateGoodsToStore(storeId, goods)`）

```
判断：findIndex(g => g.id === goods.id) >= 0
  ├─ 存在 → 替换元素（覆盖名称/价格/上下架等）
  └─ 不存在 → 不执行
结果：saveAllData()
```

### 6. 商品上下架（isOnShelf）

```
规则：商品 isOnShelf !== false 视为上架；false 为下架
  - 新增商品未显式设置 isOnShelf → 默认上架（undefined !== false）
  - 下架商品在用户端店铺详情中隐藏/不可加购
```

## 三、权限与归属判断

| 场景 | 判断逻辑 | 说明 |
|---|---|---|
| 商户入口 | 登录角色 === MERCHANT | 用户端"我的"页仅商户显示入口 |
| 店铺归属 | 只操作 ownerId === user.id 的店铺 | getStoresByOwner(ownerId) |
| 商品归属 | 商品挂在 storeId 下的 goodsMap | 修改只影响本店商品 |

## 四、边界与异常处理

| 场景 | 处理方式 |
|---|---|
| goodsMap 未初始化 | `|| {}` 兜底 |
| 店铺商品不存在 | `|| []` 兜底返回空 |
| 更新不存在的店铺/商品 | findIndex < 0 → Warn 日志 + 不执行 |
| 数据非持久化 | allStores/allGoodsMap 不在 PERSISTENCE_KEYS 中，重启还原默认店铺数据 |

## 五、数据流向

```
商户中心页
  → createStore / updateStore → allStores
  → addGoodsToStore / removeGoodsFromStore / updateGoodsToStore → allGoodsMap
  → saveAllData()（店铺/商品本身不持久化，仅 user.storeIds 落盘）
用户端读取：getAllStoresList() / getGoodsForStore(storeId)（实时反映商户修改）
```
