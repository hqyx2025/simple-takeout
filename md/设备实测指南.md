# 设备实测指南（模拟器 / 真机）

## 一、结论先说

- **设备实测不需要发布证书，也不需要 AGC。** 华为模拟器不校验发布签名，
  `entry-default-unsigned.hap` 可以直接 `hdc install`（已实测：`install bundle successfully`）。
  所以"不做 Release/签名"与"能做设备实测"并不冲突。
- **模拟器必须用 `-noWindow` 启动**：本机带窗口启动会报 `GLib: g_hash_table_remove_all: assertion` 并退出，
  无窗口模式约 40–60 秒后在 `hdc list targets` 中出现（`127.0.0.1:5555`）。
- 应用访问宿主机后端走 `http://10.0.2.2:9000`（模拟器 NAT 别名，已固化在 `API_CONFIG.DEV_BASE_URL`），
  **后端必须先启动**，否则应用内所有接口失败。

## 二、一条命令跑完（推荐）

```powershell
# 1) 先起后端（另开一个终端，保持运行）
$env:JAVA_HOME="C:\Program Files\Java\jdk-25.0.2"; mvn -f server/pom.xml spring-boot:run

# 2) 启动模拟器 + 构建 + 安装 + 拉起 + 截图 + 读界面
powershell -ExecutionPolicy Bypass -File scripts/device-test.ps1 -Start

# 常用变体
powershell -ExecutionPolicy Bypass -File scripts/device-test.ps1 -Dump    # 只读当前界面文本（排障）
powershell -ExecutionPolicy Bypass -File scripts/device-test.ps1 -Stop    # 关闭模拟器
```

脚本做的事：复用/启动模拟器 → 探测后端 → `hvigor assembleHap` → `hdc install` → `aa start` →
`snapshot_display` 截图到 `device-screenshot.jpeg` → 用 `uitest dumpLayout` 把界面文本打到控制台。

## 三、手动等价命令（想自己控制时）

```powershell
$hdc = "C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe"
$emu = "C:\Program Files\Huawei\DevEco Studio\tools\emulator\Emulator.exe"

& $emu -list -details                      # 查看已部署的模拟器实例
& $emu -start "Pura X View" -noWindow      # 启动（PowerShell 里建议后台运行）
& $hdc list targets                        # 出现 127.0.0.1:5555 即就绪

& $hdc install entry\build\default\outputs\default\entry-default-unsigned.hap
& $hdc shell aa start -a EntryAbility -b com.example.jiandanwaimai

& $hdc shell snapshot_display -f /data/local/tmp/shot.jpeg
& $hdc file recv /data/local/tmp/shot.jpeg device-screenshot.jpeg     # 截图，可直接看 UI

& $hdc shell uitest dumpLayout -p /data/local/tmp/layout.json
& $hdc file recv /data/local/tmp/layout.json .ui-layout.json          # 界面元素树（含文本与坐标）
& $hdc shell uitest uiInput click 196 1808                            # 按坐标点按（1320x2232 基准）

& $hdc shell hilog -x | Select-String jiandanwaimai                   # 设备侧日志
& $emu -stop "Pura X View"                                            # 关闭
```

**看点**：`uitest dumpLayout` + `uiInput` 的组合让"无窗口/远程"环境也能真正驱动并**校验** UI——
元素树里能读到文本与坐标（本项目根目录下 `layout.json`、`current-layout.json` 就是历史上这么抓的），
再配合宿主机的后端请求日志，就能在不看图的情况下确认端到端链路是否走通。

## 四、实测中的注意事项

1. 应用**冷启动后停在登录页**，不会自动恢复登录态直达首页；用「一键登录用户/商户/管理端/骑手端」快速切换角色。
2. 首次启动若未同意隐私政策会先弹隐私弹窗，**同意前不会发起任何网络请求**（设计如此），
   所以刚启动时后端日志为空是正常的。
3. 后端日志里每条请求有两行（`[接口请求开始]` / `[接口请求结束]`），统计调用次数时注意去重；
   模拟器来的请求 client 也显示 `127.0.0.1`（NAT），区分"应用发的"与"自己 curl 的"要看时间戳。
4. 截图文件与 `.ui-layout.json` 属于本地产物，已在 `.gitignore` 中忽略，不要提交。
